# Costing Excel sources (authoritative)

Place these files in this directory (or Attach them on Cost Allocation Settings):

1. `معین حساب - قیمت تمام شده.xlsx`
2. `دپارتمان - قیمت تمام شده.xlsx`

Then run **Preview Excel Rule Generation** / **Generate Rules from Excel** on Settings.

Baseline expectations:

- 89 unique account codes (70×611, 17×621, 2×622)
- 35 CC×Department rows (34 with Department; 1 blank-dept `مشترک عمومی شرکت`)
- Combinations before exclusions: 89 × 34 = 3026
